英文跟讀網站 — 怎麼新增一課

1. 在 GitHub 的 lessons 資料夾裡，新增一個資料夾，名稱就是課名，前面加編號：
     例如  02 At the Zoo
   （編號決定排列順序，網站會顯示成 Lesson 2 / At the Zoo）

2. 在這個資料夾裡放這幾個檔案，檔名要一模一樣：

   audio.mp3     課文音檔（必要）
   english.txt   英文課文（必要）
                 一行 = 小孩要跟讀的一句。
                 行首用方括號可以加段落標題，例如：[At 7 o'clock] I got out of bed...
   chinese.txt   中文翻譯（可以不放）
                 一行對一行英文，行數要和 english.txt 一樣。
   timing.txt    每句的開始與結束秒數（可以不放）
                 沒有這個檔案時，網站會自己分析音檔斷句。
                 如果某幾句切得不準：在跟讀頁面最下面「家長用：微調」調好，
                 按「複製全部時間」，再到 GitHub 這一課的資料夾新增 timing.txt 貼上。

3. 上傳後等 1～2 分鐘，重新整理首頁，新的課就會出現。

小提醒
- 英文和中文的 txt 檔請存成 UTF-8（用 GitHub 網頁直接新增檔案、貼上文字最方便）。
- 句子太長小孩不好跟，可以在逗號處斷成兩行（中文也要跟著斷成兩行）。
- 如果首頁沒出現新的課，把資料夾名稱加進 lessons.txt 的最後一行。
